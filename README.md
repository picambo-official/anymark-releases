# AnyMark Picambo

Öffentliche Testversionen für macOS und Windows.

Download und Bedienhinweise: https://picambo.com/anymark/

Aktuelle Pakete: https://github.com/picambo-official/anymark-releases/releases/latest

Mac: Apple Silicon ab macOS 13, nicht notarisiert. Windows: x64-Testversionen ohne bestätigten Windows-Laufzeittest. Die kleine Ausgabe setzt Microsoft WebView2 voraus; das große Offline-Paket bringt eine eigene Laufzeit mit.

Die Mac-App prüft signierte Update-Manifeste und SHA-256-Prüfsummen. Nutzer entscheiden über Prüfung und Installation. Windows-Updates erfolgen manuell bei Erhalt des Datenordners.

Dieses Repository enthält ausschließlich öffentliche Releasehinweise und freigegebene App-Pakete.
